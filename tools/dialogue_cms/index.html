仮の今日・ミッション達成数を入力して、どのセリフになるか確認できます。アプリの実データは変更しません。

まちにいる住民（仮設定・最大8人）

所持状況を変更せず、チェックを付けた住民だけが「まちで2人そろう」の条件に数えられます。

ミッション達成当日の確認（仮設定）

達成セリフは当日だけ表示されます。仮の達成日と種類、累計回数を設定して確認できます。実際の履歴は変更しません。

見たことがあるセリフ（仮設定）

全キャラ共通の既読記録です。チェックしたIDを閲覧済みとして条件を確認します。

未読の「1回のみ」セリフを優先（同順位は抽選）。それ以外は条件に合う全セリフから確率抽選し、優先順位10ごとに抽選の重みが1増えます。優先0も抽選対象です。優先-1000は施設専用のため対象外。同じセリフが連続することもあります。

登録キャラクター

登録済みキャラのID・画像フォルダは変更できません。名前とプロフィールは後から編集できます。

キャラクター設定

画像は先に assets/characters/ のフォルダへ置いてね。保存時に全スプライトを検証し、Flutterの住民定義と画像登録を自動生成します。公開には Git コミットと再ビルドが必要です。

エリア一覧

4エリアのIDと順序は固定です。桜の美容室は「のんびり里」から入る室内扱いです。

特別な出現ルール（固定）

とんこ：ガチャで取得し、開店の会話（041_pig_middle_033）を見た後は中央ひろばで店番。通常の居住エリアより優先します。

つやこ：所持すると美容室が開放。美容室の住民は屋外を歩きません。きものぎつねだけでは開放しません。

屋外住民は、まちを開いたときに開放済みエリアへランダムにお出かけします。エリア移動や会話中は行き先を保ちます。デバッグ選択中は本来の居住エリアを表示します。

エリア設定

このエリアに住む子

左のエリアを選ぶと、そこを住まいにしている子だけを表示します。ここで設定するのは「住まい」で、お出かけ先ではありません。屋外住民は開放済みエリアへランダムにお出かけします。

お出かけ先のプレビュー（仮）

選択中のエリアに、今回のお出かけで現れる子の例です。全員を取得済みと仮定し、開放済みの場所からランダムに選びます。実際のアプリの現在位置やセーブデータではありません。

エリア設定・住民配置・セリフはまとめて保存します。背景の差し替えとマルシェ等の特殊条件はこの画面では変更しません。公開アプリへはGitコミットと再ビルドが必要です。
