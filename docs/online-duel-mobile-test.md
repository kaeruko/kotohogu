# スマホ2台で試験する

AWSの対戦APIを先にデプロイする。現在の試験接続先は
https://dxopo67sm9.execute-api.ap-northeast-1.amazonaws.com 。
CMSのGoogle Drive設定は変更しない。

1. 両方のスマホ（または別々のAndroidエミュレータ）に同じmainのビルドを起動。
2. 累計240ことほぎで公民館を開き、2階の待ち合わせ広場へ。
3. Aが部屋をつくる。8文字の番号をBに伝える。公開投稿には載せない。
4. Bが番号で参加する。先後はサーバーが決める。後手がいちごの旗を置く。
5. 先手が第1部屋の空欄をタップして数字を選ぶ。もう一台で盤面を確認。
6. 先に3点取れば終了。途中でアプリを閉じ、待ち合わせ広場の
   「対戦のつづき」で戻れる。期限は部屋作成から24時間。

通信は待機中・相手の手番中の3秒間隔のGET。バックグラウンドでは停止する。
失敗時はエラーを表示して自動更新を止め、盤面を更新ボタンで再取得する。
更新要求の暗黙再送はしない。入室時に応答が失われた場合は
同じ番号で入室を確認ボタンを使う。部屋作成時の応答紛失は復元できない。
保存済み対戦は1部屋。試験版の認証トークンはSharedPreferencesに保存する
（暗号化されたキーチェーンではない）。一般公開前に安全な保存と
バックアップ除外、悪用対策、盤面カタログを検討する。
ブラウザ版は未対応。既存のCPU道場・ストーリー・演出は変更しない。
オンライン画面には既存のCPU演出・候補メモはまだ移植していない。
