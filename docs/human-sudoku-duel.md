# 対人コトホグル（4×4試作ルール）

- 先手・後手を割り当てた後、後手が1〜4の部屋から特別な旗を1本選ぶ。
- 先手は第1部屋から開始し、以後は置いた数字で相手の送り先を指定する。
- 送り先に空欄がなければ空欄のある任意の部屋を選べる。
- 部屋の最後の空欄を埋めた人が旗を獲得。普通の旗は1点、特別な旗は2点。
- 先に3点以上を獲得した人が勝ち。合計5点のため引き分けはない。
- 誤入力では盤面も手番も変えない。オンライン版ではサーバーが判定する。

## 初期盤面と検証

初期盤面は `1004301020034020`、解答は `1234341221434321`。
4部屋すべてに空欄があり、シングル候補のみで解ける。
合法な正解手をすべて列挙した場合、全ての旗配置で双方に勝つ経路がある。

| 特別な旗 | 最善手同士の勝者 | 一様ランダムな合法手での先手勝率 |
|---|---|---:|
| 1 | 後手 | 50.00% |
| 2 | 後手 | 48.96% |
| 3 | 後手 | 48.96% |
| 4 | 先手 | 52.08% |

ランダム選択の勝率は実際の人間の勝率ではない。後手が1〜3を選んで
最善手を続ければ勝てるため、完全な公平性は保証しない。
オンライン公開前に盤面カタログと先後割当の設計を別途検討する。
数独の数字を入れ替えると送り先も変化するため未検証のランダム変換は行わない。

現段階は既存の Dart 対戦エンジンに専用ファクトリを追加したのみ。
オンライン認証、入室、後手による選択の権限検証、通信、対戦UIは未実装。
CPU道場・ストーリーのルールと問題カタログは変更しない。
